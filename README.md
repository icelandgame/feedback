# IceLAND 問題回報與建議

這裡是 [IceLAND](https://icelandtw.xyz) 公開的回報區：遊戲或網站的 bug、想要的功能、譜面的問題，都可以在這裡開 Issue。

遊戲本身的程式碼不在這裡。

## 怎麼回報

1. 先用上面的搜尋找找看，有沒有人回報過一樣的問題。有的話，在那一則底下留言補充，或按個 👍。
2. 沒有的話，按 **Issues → New issue**，選一種：
   - **Bug 回報**：遊戲或網站壞掉、表現和預期不同。
   - **功能建議**：想要的新功能，或現有功能的改進。
   - **譜面問題**：譜面錯誤、音樂時間對不上、授權疑慮、不當內容。
3. 照著欄位填。Bug 回報一定要附「怎麼重現」，能附截圖或影片最好。

**遊戲版本**在標題畫面的右下角，例如 `BETA 2026-11 BUILD 11`。

## 不要貼在這裡的東西

這裡的內容**所有人都看得到**，以下的東西請不要貼：

- 密碼、信箱、登入碼、任何 token。
- 帳號、付款、隱私相關的問題。請寄信到 support@icelandtw.xyz。
- **資安漏洞**（例如可以偽造成績、看到別人的資料）。請不要公開，寄信到 support@icelandtw.xyz。

## 回報之後

- 我們看過之後會加上標籤：「確認中」表示正在查，「已修好」表示修正會在下一個版本出現。
- 修好的東西會寫在遊戲的更新紀錄裡。
- IceLAND 由兩個人在開發，不一定能馬上回覆，請見諒。

## 規則

請友善發言。人身攻擊、洗版、廣告會被刪除。
